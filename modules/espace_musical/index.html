Utiliser l’espace choristes

Programmes : le programme {{$cc.season}} rassemble les chants à travailler dans l’ordre. Le répertoire conserve toutes les fiches. Les responsables peuvent attribuer un ordre de travail ; la valeur 0 laisse le chant hors programme.

Morceaux : ouvrez une fiche pour retrouver les consignes, les paroles et les fichiers. Les noms de fichiers peuvent préciser le pupitre : Soprano, Alto, Ténor, Basse ou Tous.

Agenda : ouvrez une répétition ou un concert, choisissez votre pupitre et indiquez votre disponibilité. Vous pouvez modifier votre réponse à tout moment.

Responsables : les membres autorisés à modifier le site web ou à administrer la configuration peuvent publier et modifier les contenus, joindre des fichiers et consulter le bilan des présences. Les archives peuvent être restaurées.

Les annonces sont consultables ici. Pour les courriels, utilisez « Messages collectifs » : Paheko permet de rédiger le message et de choisir les destinataires avant l’envoi. Les rappels automatiques ne sont pas activés.
