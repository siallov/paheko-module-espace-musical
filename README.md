# Espace musical configurable — module Paheko

Espace choristes, atelier musical, lecteur de partitions et accès à la conversion PDF vers MusicXML.

## Installation

Le dossier du module est `modules/espace_musical/`. Utilisez ce dossier avec la procédure d’installation des modules personnalisés correspondant à votre instance Paheko. Ne déplacez pas `module.ini` hors de ce dossier.

Vérifiez la compatibilité avec la version de Paheko utilisée avant le déploiement.
